# Frontend — Explainable Insurance Claim Severity System

Next.js product interface for the platform. Five surfaces: Overview, Scoring, Explainability, Monitoring, Governance. See the [root README](../README.md) for full system documentation and the [Experience Flow](../docs/EXPERIENCE_FLOW.md) for a guided walkthrough.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Configuration

Requires `NEXT_PUBLIC_API_URL` pointing at the backend base URL (see root README's Deployment section).

## Build

```bash
npm run build
npm run start
```
